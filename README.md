# Mol’bert Epstein — editorial website

Статичный адаптивный сайт (HTML + CSS + немного JS), собранный из макета Figma (десктоп 1440px).
Без сборщика и зависимостей — открывается двойным кликом по `index.html`.

## Структура

```
index.html              разметка (секции подписаны комментариями)
css/style.css           все стили; токены цветов и шрифтов — в :root
js/main.js              мобильное меню + проверка формы подписки
assets/img/             фотографии (см. ниже)
scripts/download-assets.sh   (необязательно) заново скачать фото из Figma, ссылки живут 7 дней
```

## Фото

Все 6 фото уже лежат в `assets/img/` (прозрачные PNG). Если нужно заменить — подставь файл с тем же именем.

| Файл                  | Где используется                               |
|-----------------------|------------------------------------------------|
| `cover-portrait.png`  | обложка (вырезанный портрет в круге)           |
| `portrait-smile.png`  | эссе на красном фоне + 2-я карточка журнала    |
| `seated.png`          | цитата на тёмном фоне + 1-я карточка журнала   |
| `archive-candid.png`  | архив, 1-я фотография (оригинал, кроп в CSS)   |
| `archive-playful.png` | архив, 2-я фото + 3-я карточка журнала (повёрнута на 173.6° в CSS) |
| `standing.png`        | архив, 3-я фото + большой блок «Featured»      |

## Адаптив

- Брейкпоинты: `900px` (колонки становятся стопкой), `860px` (бургер-меню), `600px` (мобайл).
- Отступы и размеры шрифтов плавные: `clamp()` от значений в макете (на 1440px совпадают с Figma 1-в-1).
- Фото-композиции (красные плашки, круги, подложки) заданы в процентах от контейнера,
  поэтому масштабируются вместе с фото и не «разъезжаются».

## Выложить на GitHub Pages

1. Создай репозиторий и загрузи все файлы (включая `assets/img/`).
2. Settings → Pages → Source: `Deploy from a branch` → `main` / `(root)`.
3. Через минуту сайт будет на `https://<логин>.github.io/<репозиторий>/`.
